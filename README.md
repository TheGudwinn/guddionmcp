# Guddion MCP

Каталог ваших локальных проектов и делегирование рутинных задач дешёвым моделям — прямо из Claude Code.

## Зачем

У Spotify есть `portal-ai-plugins` — внутренний инструмент, который подключает Claude Code/Codex/Cursor к каталогу сервисов компании и умеет откидывать рутинные подзадачи на более дешёвые модели. Штука полезная, но платная и корпоративная.

Guddion MCP — то же самое по духу, но открытое:

- **Каталог ваших локальных проектов** прямо в Claude Code — поиск и briefing по любому проекту без переключения окон.
- **Делегирование рутинных подзадач** дешёвой модели — вместо того чтобы жечь дорогие токены на то, что не требует мощной модели.
- Код никогда никуда не уходит с вашей машины — каталог живёт только локально.

## Установка

```bash
npm install -g guddion-mcp
```

Зарегистрируйтесь на [mcp.guddion.ru](https://mcp.guddion.ru), получите API-токен в личном кабинете (раздел «API-ключи») и укажите его в конфиге агента — никакого своего сервера поднимать не нужно.

## Как это устроено

Пакет `agent/` в этом репозитории — сам MCP-агент (Node/TypeScript, stdio): сканирует ваши локальные директории и даёт Claude Code инструменты `search_projects`, `get_project_briefing`, `delegate_task`. Он полностью открытый — можно поставить как есть, а можно собрать свой composable-сервер поверх `registerCoreTools` (см. `agent/README.md`).

Делегирование задач (`delegate_task`) обращается к бэкенду guddion.ru, который проксирует вызов к настроенному провайдеру и списывает стоимость с вашего баланса — без своего сервера и без своего API-ключа провайдера.
